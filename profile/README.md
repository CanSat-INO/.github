# CanSat INØ

CanSat INØ の開発用 GitHub Organization です。ソフトウェア・電装・機構の開発課題、実験結果、設計判断を共有します。

## 開発に参加する

- [開発リポジトリ INO](https://github.com/CanSat-INO/INO)
- [開発課題・実験の記録](https://github.com/CanSat-INO/INO/issues)
- [開発への参加方法](https://github.com/CanSat-INO/.github/blob/main/CONTRIBUTING.md)
- [Organization の Projects](https://github.com/orgs/CanSat-INO/projects)

作業は Issue で目的と完了条件を共有し、変更は Pull Request で確認します。実験では条件・判定基準・結果・ログを残します。

公開資料には認証情報や個人情報を含めないでください。
